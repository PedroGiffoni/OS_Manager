# Contexto do domínio

## Quadro

Espaço de trabalho independente para organizar cards, sprints, fluxo, filtros, automações, planejamento e relatórios. Um quadro define uma fronteira de acesso; seus dados não aparecem em outro quadro.

## Membro do quadro

Usuário explicitamente autorizado a acessar um quadro. Administradores podem acessar todos os quadros; fornecedores, mesmo como membros, só consultam cards atribuídos à própria conta.

## Quadro principal

Quadro criado para receber os dados existentes durante a migração. O histórico atual permanece associado a esse quadro.
