# Assets dos relatórios

Logotipo e composição visual seguem o arquivo Farol Estratégico fornecido como referência.
Figtree normal/negrito e Lato vêm dos pacotes @fontsource fixados no frontend; licenças OFL incluídas. TTF convertidos dos WOFF usando fonttools durante desenvolvimento, sem dependência em execução.
report.css contém o layout claro, responsivo, impressão e movimento reduzido com tokens semânticos.
HTML incorpora fontes, logo e estilos. PDF incorpora TTF com ReportLab. Não há requisições externas.
